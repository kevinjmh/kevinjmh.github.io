安装 Rust（如果没有）

winget install Rustlang.Rustup
https://win.rustup.rs/x86_64

安装 Node.js

winget install OpenJS.NodeJS.LTS

创建项目（推荐用 pnpm）

npm create tauri-app@latest my-toolbox – –template react-ts
cd my-toolbox
pnpm install

前端依赖

pnpm add @tauri-apps/plugin-clipboard-manager @tauri-apps/plugin-global-shortcut @tauri-apps/plugin-shell @tauri-apps/plugin-store lucide-react zustand clsx tailwindcss postcss autoprefixer

初始化 Tailwind

pnpm dlx tailwindcss init -p

开发模式

pnpm tauri dev
在x64 Native Tools Command Prompt for VS 2022中执行以支持使用link.exe

打包发布

pnpm tauri build
